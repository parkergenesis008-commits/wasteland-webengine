war between civilizations that treat reality as source code.

## About this repository

Static site (GitHub Pages). Pages are generated by `pipeline/build_site.py` from
`site_structure.yaml` and `pipeline/templates/*.html`; structured data (JSON-LD), `llms.txt`
and `sitemap.xml` are produced by the same pipeline.

```bash
python3 pipeline/build_site.py     # regenerate published HTML, sitemap.xml, llms.txt
```
